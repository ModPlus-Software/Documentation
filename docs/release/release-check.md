# Проверка релизной версии плагина

Актуально для записи видео по плагину, который готовится к релизу

Обычно к моменту релиза информация о стандартном меню уже загружена на сервер.

Собираем плагин нужной версии, выбрав соответствующую конфигурацию.

Открываем папку расположения ModPlus (можно через модуль автообновлений), заходим в папку Functions, затем в папку с именем продукта (AutoCAD, Revit) и создаем папку с именем нашего плагина.

Копируем в созданную папку собранные релизные dll.

Запускаем Конфигуратор (можно через модуль автообновлений). Плагин должен появиться в списке доступных (будет без иконки). Переходим в раздел "Адаптация", выбираем меню своего продукта (AutoCAD, Revit) и жмем кнопку "Построить стандартно"
