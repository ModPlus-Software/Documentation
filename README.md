Этот проект служит для хранения документации по разработке, а также сопутствующую документацию.

**Сайт документации: https://modplus-software.github.io/Documentation/**

## Как это устроено

- Исходники страниц — обычные Markdown-файлы в папке `docs`, разложенные по разделам.
- Сайт собирается генератором [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) и публикуется на GitHub Pages автоматически при каждом push в `main` (workflow `.github/workflows/docs.yml`).
- Оглавление сайта задаётся секцией `nav` в `mkdocs.yml`. Файл, не добавленный в `nav`, в боковое меню не попадёт.

## Как добавить или изменить страницу

Самый быстрый способ — нажать на сайте кнопку с карандашом в правом верхнем углу страницы: откроется веб-редактор GitHub с нужным файлом.

Вручную:

1. Создать `.md`-файл в подходящей папке внутри `docs` (имя файла — латиницей, через дефис: `logging-service.md`).
2. Первой строкой файла поставить заголовок страницы: `# Название страницы`.
3. Добавить путь к файлу в секцию `nav` в `mkdocs.yml`.
4. Закоммитить в `main` — через 1-2 минуты сайт обновится.

Ссылки между страницами — относительные, на `.md`-файл: `[Работа с настройками](user-settings.md)` для соседней страницы, `[Конвертеры](../ux-ui/converters.md)` для страницы в другом разделе. Сборка идёт в режиме `--strict`, поэтому опечатка в ссылке уронит workflow и страница не опубликуется с битой ссылкой.

Картинки можно класть в `docs/assets` и ссылаться относительным путём, либо оставлять внешние ссылки на вложения GitHub — они работают.

## Локальный предпросмотр

```
pip install -r requirements.txt
mkdocs serve
```

Сайт откроется на http://127.0.0.1:8000 и будет перезагружаться при сохранении файлов.
